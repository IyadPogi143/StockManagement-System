# Stock Management System

## Project Description
A web-based Stock Management System developed using Spring Boot, ReactJS, and PostgreSQL. The system allows users to register, log in, and manage inventory based on their assigned roles.

## Technologies Used
- Spring Boot
- ReactJS (Vite)
- PostgreSQL
- Maven
- Git & GitHub

## Features
- User Registration
- User Login
- Role-Based Access
- Dashboard
- PostgreSQL Database Integration

## Running the Backend

```bash
cd backend
mvnw spring-boot:run
```

## Running the Frontend

```bash
cd web
npm install
npm run dev
```
